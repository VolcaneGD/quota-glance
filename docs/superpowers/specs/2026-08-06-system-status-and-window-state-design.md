# System Status and Window State Design

## Goal

Quota Glanceに小型のシステム状態表示、透明度設定、ウィンドウ状態の永続化、さらに縮小したミニマムモードを追加する。あわせて、GitHub上の誤ったコミット帰属を修正する。

## System status strip

残高カードの直前へ**Status Strip**を置く。GPU、CPU、MEM、TEMPを横並びで小さく表示する。

- CPU: Windows標準のPowerShell経由で使用率を取得する。
- MEM: Windows標準のPowerShell経由で使用率を取得する。
- GPU / TEMP: `nvidia-smi`が利用可能なNVIDIA環境でGPU使用率とGPU温度を取得する。
- 取得不能な項目は`--`を表示する。GPUがない、NVIDIA以外、またはコマンド失敗時も同じ扱いとする。
- 使用率は50%未満を緑、50%以上80%未満を黄、80%以上を赤とする。温度は60℃未満を緑、60℃以上80℃未満を黄、80℃以上を赤とする。
- 更新は既存のユーザー設定済み更新頻度に合わせる。

## Settings and persistence

更新頻度スライダーの直後へ**Settings Panel**として透明度スライダーを追加する。透明度は40%から100%まで、既定100%とする。

次の状態をアプリ専用のローカル設定ファイルへ保存し、起動時に復元する。

- ウィンドウ位置とサイズ
- 日本語 / 英語
- 更新頻度
- ウィンドウ透明度
- ミニマムモード

画面外に保存された位置は、現在利用可能なディスプレイ領域へ戻す。ミニマムモード中は小型サイズを優先し、通常表示へ戻ると直前の通常ウィンドウサイズへ戻す。

## Compact View

**Compact View**では残クレジット、5時間枠の残り%、週間枠の残り%を保持する。数値のフォントサイズ、各カードのpadding、カード間隔、タイトルバーをさらに縮める。Status Strip、透明度、更新頻度、詳細なリセット情報は通常表示だけに置く。

## GitHub attribution

`volcane@users.noreply.github.com`はVolcaneGDではない別アカウントに紐づくため使用しない。今後のコミットは`volcane.gd@gmail.com`をリポジトリローカル設定へ設定する。

Quota Glanceの既存4コミットは作者・コミッターのメールを`volcane.gd@gmail.com`へ書き換え、GitHub上の表示を正しいアカウントへ関連付ける。この操作は公開履歴の書き換えを伴うため、`main`へ強制プッシュする。

## Testing

- システム状態の正規化、しきい値色、取得不能時の`--`をNodeテストで検証する。
- 保存済みウィンドウ状態の検証と画面外位置の補正をNodeテストで検証する。
- レンダラーの表示契約をテストする。
- 通常表示とCompact Viewの実画面を確認し、透明度・スライダー・ミニマム切替を操作する。
