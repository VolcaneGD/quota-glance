# Webサイト掲載文

## タイトル

Quota Glance — Codexの利用状況を小さく、見やすく。

## 短い紹介文

Quota Glanceは、Codexの残りクレジット、週間使用率、次回リセット日時をデスクトップに常時表示できる、Windows向けの無料・非公式ユーティリティです。

## 特徴

- 残りクレジットと週間使用率をひと目で確認
- 次回リセット日時と残り時間を表示
- 日本語・英語に対応
- タスクトレイ常駐、常に手前に表示
- インストール不要のポータブルアプリ
- 広告、テレメトリー、外部へのデータ送信なし

## 重要な説明

Quota Glanceは、Codexが端末内に保存した最新の利用状況を表示します。公式APIへ独自問い合わせするアプリではないため、Codexを利用していない間にサーバー側だけで値が変わった場合は、次のCodex応答後に同期されます。

Quota GlanceはVOLCANEが独立して開発した非公式ツールであり、OpenAIによる提供、承認、後援、提携、サポートを受けた製品ではありません。

## English copy

### Quota Glance — Keep your Codex usage in sight

Quota Glance is a free, unofficial Windows utility that displays your remaining credits, weekly usage, and next reset time in a compact desktop window.

- Japanese and English interface
- Always-on-top window and system tray indicator
- Portable; no installation required
- No ads, telemetry, analytics, or external data transmission

Quota Glance reads the latest usage snapshot recorded locally by Codex. It does not independently query an official real-time API. Quota Glance is independently developed by VOLCANE and is not provided, endorsed, sponsored, affiliated with, or supported by OpenAI.

Latest release: https://github.com/VolcaneGD/quota-glance/releases/latest
