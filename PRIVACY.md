# プライバシーポリシー / Privacy Policy

最終更新日: 2026年10月3日

## 日本語

Quota Glanceは、利用者の個人情報・利用統計を開発者へ送信しません。広告、テレメトリー、クラッシュレポート、アクセス解析機能はありません。任意で登録するX APIトークンはWindowsで暗号化して端末内に保存し、X APIへの認証にだけ送信します。

本ソフトウェアは、利用状況を表示するため、利用者の端末内にあるCodexのローカルセッションファイルを読み取ります。読み取った内容から利用上限、リセット日時、クレジット状態に関する`rate_limits`情報だけを抽出し、端末内の画面とタスクトレイに表示します。セッション本文、プロンプト、回答、認証トークン、APIキーを外部へ送信することはありません。

ウィンドウ・表示設定、告知キャッシュ、通知設定と重複防止履歴は端末内に保存します。公開JSON・公式ステータスRSSを取得し、任意のX API設定時はX APIに接続します。配信元には通常の接続情報（IPアドレスなど）が届きますが、Codexセッション本文・利用量・端末識別子は送信しません。公開フィードには原典URL・作者・公開日時・対象・予定時刻などの構造化メタデータを含みます。投稿全文・画像・返信・APIトークン・Googleアラートの非公開RSS URLは公開しません。

## English

Quota Glance sends no personal information or usage analytics to its publisher. It contains no advertising, telemetry, crash reporting, or analytics. An optional user-owned X API token is stored locally with Windows encryption and sent only to X API for authentication.

To display usage information, the software reads Codex session files stored locally on the user's device. It extracts only `rate_limits` information related to usage limits, reset times, and credit status for local display in the window and system tray. It does not transmit session content, prompts, responses, authentication tokens, or API keys.

Window preferences, announcement cache, notification settings and deduplication history remain on the device. The app retrieves a public JSON feed and official status RSS, and optionally connects to X API. Hosts receive ordinary connection data such as an IP address, but no Codex session content, usage values or device identifiers. Public schema-v3 metadata includes source URL, author, publication time, scope and announced timing. Full text, media, replies, tokens and private Alerts URLs are never published.
